# 📊 Product Sales Analysis

## 📌 Project Overview

Product Sales Analysis is a data analytics project focused on analyzing sales data to identify sales trends, product performance, sales effectiveness, source performance, and sales agent performance.

The project uses Python and data visualization techniques to clean, analyze, and transform raw sales data into meaningful business insights.

## 🎯 Project Objective

The main objective of this project is to analyze sales data and identify important patterns and trends that can help understand business performance and support data-driven decision making.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
- Power BI

## 🔄 Data Analysis Process

1. Data Collection
2. Data Cleaning
3. Data Preprocessing
4. Exploratory Data Analysis (EDA)
5. Data Visualization
6. Business Insights
7. Dashboard Creation

## 🧹 Data Cleaning

- Removed duplicate records
- Handled missing values
- Standardized categorical values
- Converted date columns into proper datetime format
- Checked data types
- Performed data quality validation

## 📊 Analysis Performed

### 📈 Sales Analysis

- Analyzed overall sales performance
- Identified sales trends
- Compared sales across different categories

### 🛍️ Product Analysis

- Analyzed product performance
- Identified high-performing products
- Compared product-level sales results

### 👨‍💼 Sales Agent Analysis

- Compared sales agent performance
- Identified sales contribution
- Analyzed sales effectiveness

### 📢 Source Analysis

- Analyzed lead/source performance
- Compared different sources
- Identified effective sources

### 📍 Location Analysis

- Analyzed sales performance by location
- Compared different locations
- Identified important location-level patterns
